Baseline Model
Baseline model adalah model dasar, biasanya model
sederhana yang dapat digunakan sebagai landasan
pengukuran model Machine Learning. Tujuan dari
baseline model adalah untuk menetapkan nilai model
dasar yang dapat dipertimbangkan dan harus dilampaui
oleh hasil uji lanjutan model Machine Learning.
Secara umum, baseline model berguna untuk
menentukan konsistensi model yang dilatih. Hal ini juga
membantu dalam evaluasi dataset. Oleh karena itu,
baseline model harus selalu menjadi model pertama yang
Anda kembangkan dalam proyek pembelajaran mesin.

Overfitting
Overfitting terjadi ketika machine learning model
memberikan prediksi akurat untuk data pelatihan
tetapi tidak ketika digunakan pada data baru atau
data validasi. Dalam machine learning mengatakan
bahwa model adalah overfit jika performa tampak
sangat baik saat Training, tetapi sangat buruk atau
bahkan berantakan saat diujikan pada data lain diluar
data training atau pada saat model diuji
menggunakan data validation. Sebagai contoh,
sebuah model menunjukkan performa akurasi
sebesar 100% akurat pada training data, dan 50%
pada testing data lain.

## --- Page 16 ---

Underfitting
Underfitting adalah keadaan di mana model machine
learning tidak dapat mempelajari hubungan antara
variabel dalam data dengan baik dan tidak dapat
memprediksi atau mengklasifikasikan data baru secara
akurat.
underfitting menyebabkan model gagal dalam melakukan
generalisasi dan menghasilkan prediksi yang tidak akurat.
Dalam analogi, overfitting mirip dengan siswa yang
menghafal pertanyaan ujian tanpa memahami konsep
materi, sedangkan underfitting mirip dengan siswa yang
tidak memahami konsep materi dan hanya
mengandalkan asumsi/pendapat sendiri.

## --- Page 18 ---

Kesimpulan umum fitting data dalam machine learning 
terbagi menjadi 4, yaitu:
1. Underfitting – Validation dan training nilai error-nya tinggi
2. Overfitting – Validation error tinggi, training error rendah
3. Good fit – Validation error rendah, atau sedikit lebih tinggi
dibandingkan dengan Training error
4. Unknown fit - Validation error rendah, training error “tinggi”
